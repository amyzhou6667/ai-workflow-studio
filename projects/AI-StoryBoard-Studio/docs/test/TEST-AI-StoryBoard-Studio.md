# 测试用例文档 (TEST-AI-StoryBoard-Studio)

- **项目名称**：AI-StoryBoard-Studio 多智能体可插拔工作流分镜工场
- **关联需求**：`projects/AI-StoryBoard-Studio/docs/prd/PRD-AI-StoryBoard-Studio.md`
- **生成日期**：2026-11-11
- **设计标准**：六维测试检查表（字段级/操作级/权限级/状态级/异常级/数据级）
- **核心架构**：基于 4 个专业 Agent（资产提取、剧本改编、镜头切分、生图Prompt）的可插拔多智能体流水线 (Multi-Agent Pipeline)

---

## 1. 测试范围与前置条件

### 1.1 被测核心功能模块
1. **多智能体工作流流水线看板 (Workflow Stepper Pipeline)**：串行推进、单步独立重跑、节点直通跳过。
2. **资产提取 Agent (Asset Extractor)**：角色库提取、服装神态、Trigger Prompt、--cref 绑定及场景提取。
3. **剧本改编 Agent (Scriptwriter)**：小说重构为影视剧本、场次环境动作正文描写、带情绪台词与独白。
4. **镜头切分 Agent (Director Shot)**：影视视听语言切分、景别/运镜/时长配置、角色与台词映射绑定。
5. **生图 Prompt Agent (Visual Prompt)**：三模型（Midjourney v6.1 / Flux.1 / 即梦）提示词组装与纯英参数保障。
6. **工业物料导出与交付 (Export Formatter & SRT Engine)**：剪映标准高保真 SRT 字幕、BOM 头防乱码 CSV 分镜母表、全套 Prompt 清单。
7. **可插拔 Agent 工坊配置中心 (Agent Hub)** 与 **Prompt 视窗弹窗体系 (Prompt Modal)**。

### 1.2 前置与运行环境
- 运行依赖：Node.js v22+ / TypeScript 7.0 / tsx / React 18 / Ant Design 6 / TailwindCSS
- 被测服务端口：本地 HTTP 服务 `http://127.0.0.1:3000`
- 测试套件命令：`pnpm test` (基于 Node 22 原生 `--test` 驱动)
